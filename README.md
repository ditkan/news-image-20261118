One front page with Wednesday 18 November 2026's world news: 150 numbered stories across 6 continents, a dot-grid world map with story markers, the day in numbers and a wire ticker.

The image (`entry.png`, 1024×1024) is drawn by `render.py` — a Pillow
renderer written for this entry — from a hand-researched list of the
day's 150 biggest stories (see `sources.txt` for the full list and the
reports behind each item). At run time, `main.py` (Python standard
library only) copies the shipped image byte-for-byte into the output
directory, so repeated runs are identical.

## Run it

```sh
python3 main.py
```
